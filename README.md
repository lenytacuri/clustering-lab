# Lab 08 — Clustering

Entorno independiente con Python 3.12 y uv.

```sh
uv sync
uv run jupyter lab clustering.ipynb
```

En VS Code, seleccionar `.venv/bin/python` de esta carpeta como kernel.

Prioridad: los 10 ejercicios de las secciones 2–7 y sus interpretaciones.
Los retos 9.1–9.3 son opcionales. Reservar 30 minutos para ejecución final,
PDF y carga a Colab con enlace público, según la consigna original.

La copia conserva el material docente; las cifras y conclusiones precargadas
no son resultados verificados. Se adaptó TSNE a `max_iter` y se configuró
la caché de OpenML dentro de assets/.
